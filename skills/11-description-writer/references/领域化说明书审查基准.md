# 领域化说明书审查基准

## 通用审查

- 技术问题、技术方案和技术效果形成可验证因果链。
- 每项权利要求特征有具体说明书和附图支持，术语前后一致。
- 宽泛概括有多个实施方式、替代方式或一般原理支撑，不以单一实施例无限外推。
- 参数、范围、材料、步骤顺序和效果均有来源；端点和优选范围有依据。
- 所属领域技术人员可以据此实现，不需要创造性劳动或过度试验。

## 机械装置

- 说明部件形状、相对位置、连接/配合方式、装配关系、运动约束和工作过程。
- 对实现效果必需的尺寸关系、间隙、角度或材料说明依据；非必要时提供合理替代。
- 图中状态、剖切和爆炸关系在正文中能够还原为真实装配结构。

## 电气与控制系统

- 说明模块功能、端口、信号方向、电源/接地、数据或控制关系及工作时序。
- 仅写“模块用于实现某功能”通常不足；应说明能够实现该功能的连接、处理逻辑或关键条件。
- 硬件、软件和控制流程之间应有对应关系。

## 软件与算法

- 说明执行主体、输入数据、处理步骤、关键数据结构/模型、输出及其与硬件或具体技术场景的关系。
- 技术效果应来自具体技术手段，不以商业收益、管理便利或抽象算法性能替代。
- 对关键模型训练、参数、规则或流程提供足以实现的说明，同时避免把非必要实现细节写成唯一方式。

## 方法与工艺

- 明确步骤主体、先后/并行关系、条件分支、输入输出、工艺条件和异常处理。
- 说明步骤之间为何共同解决技术问题，避免仅罗列互不关联操作。
- 范围、顺序或条件可变时，分别说明可变边界及其影响。

## 化学技术

- 核对化合物名称、结构式、取代基、立体化学、原料、反应条件、纯化、表征和产率。
- 宽泛通式或数值范围需要足够代表性实施例和可合理预期的效果支持。
- 实验数据、比较例和效果不得生成；缺少时明确要求发明人补充。

## 生物技术

- 说明序列、载体、宿主、样本、试剂、实验条件、检测方法、统计或功能验证及可重复性信息。
- 涉及序列、保藏、遗传资源或来源披露等事项时单独列出合规核对项，交执业代理师确认。
- 诊断、治疗或用途主题存在保护客体风险时，不得仅靠改标题规避，应回到技术事实和权利要求策略审查。

## 混合发明

- 分别满足各相关领域公开要求，并通过统一接口表说明机械、电气、软件、流程或化学/生物部分如何协同。
- 不得让不同领域章节使用不一致的部件、模块、步骤或效果名称。
